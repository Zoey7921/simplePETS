# simplePETS：MuJoCo 世界模型入门方案

记录日期：2026-10-22。

## 目标与选择

先用 MuJoCo 倒立摆跑通“学习动力学模型 + 模型预测控制（MPC）”，再升级到 Reacher 机械臂到达任务。采用 PETS 的简化实现，先理解预测和闭环控制，再逐步加入不确定性建模。

世界模型学习“状态和动作如何决定下一状态”；VLA 根据视觉和语言指令输出动作。世界模型可以从低维位置、速度入门，不必先处理图像和语言。当前硬件适合这条路线；完整 VLA 训练可留到后续借助远程 GPU，本机用于仿真评估。

## 算法路线

经典参考：PETS，2018 年论文 *Deep Reinforcement Learning in a Handful of Trials using Probabilistic Dynamics Models*。

论文：https://arxiv.org/abs/1805.12114

闭环流程：采集交互数据 → 学习动力学 → 预测候选动作序列 → 选择动作 → 在 MuJoCo 执行 → 补充数据并更新模型。

- **教学版本**：小型 MLP 输入当前状态和动作，预测状态变化；用随机采样搜索动作序列。MPC 每次只执行所选序列的第一步，获得真实新状态后重新规划。
- **逐步接近 PETS**：加入概率动力学模型集成、粒子轨迹采样和 CEM（交叉熵方法）动作优化，研究预测不确定性如何影响控制。

教学版本称为“简化世界模型 + MPC”，不等同于完整 PETS 复现；完整复现需核对论文及实现细节。

## 实验阶段

| 阶段 | 工作 | 验收结果 |
|---|---|---|
| 1 | 跑通 Gymnasium MuJoCo `InvertedPendulum-v5` | 理解 reset、step、状态、动作与回合结束 |
| 2 | 采集数据并训练动力学 MLP | 在留出轨迹上评估一步和多步预测误差 |
| 3 | 接入 MPC 控制 | 对比随机动作的回报和保持平衡时长 |
| 4 | 加入模型集成、粒子采样与 CEM | 比较控制效果、预测误差和计算开销 |
| 5 | 迁移到 `Reacher-v5` | 用学到的动力学完成目标到达 |

倒立摆用于检查流程；Reacher 作为第一个完整小项目。倒立摆任务简单、标准奖励较简单，仅保持平衡不足以证明世界模型准确。

## 起步环境与参数

- 新建独立 Python 3.11 环境，安装 CPU 版 PyTorch、Gymnasium MuJoCo 和绘图工具；保留现有 UR5e 教程环境。
- 使用低维状态，不输入摄像头图像。
- 动力学网络：2 个隐藏层，每层 64～128 个单元。
- 首批采集约 5000～10000 个交互步，再根据控制效果补数据。
- MPC 规划时域先设 10～20 步；候选动作序列从几十到一两百条试起。
- 训练和采样时关闭渲染，评估时打开窗口。

上述参数仅是调试起点，速度需实测。MPC 反复调用网络，规划开销可能高于 MuJoCo 物理仿真开销。

## 评估与科研习惯

- **预测**：一步误差，以及连续预测 5、10、20 步后的误差。
- **控制**：多个随机种子下的平均回报、波动、环境交互步数；倒立摆记录平衡时长，Reacher 记录目标距离或明确阈值下的成功率。
- **成本**：训练耗时、每次规划耗时。
- 按整段轨迹划分训练集与测试集，避免相邻样本混入两边导致评估过于乐观。

首个项目目标：在 MuJoCo Reacher 上，用自己学到的动力学模型完成目标到达，并解释预测误差如何影响控制效果。之后可继续学习 Dreamer 的图像潜空间世界模型，或机械臂视觉模仿学习与语言条件策略，逐步进入 VLA。
